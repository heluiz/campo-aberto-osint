# Campo Aberto — diretório OSINT

Painel estático em português com 20 fontes públicas, busca e filtros por categoria. Abra `index.html` no navegador; não requer instalação, conta, servidor ou dependências.

O painel funciona localmente. Os links externos precisam de internet e podem mudar. O projeto não realiza consultas automáticas, coleta nem armazena dados.

- [Instruções de uso](LEIA-ME.md)
- [Fontes da entrega original](fontes-verificadas.md)

Esta cópia foi preparada para revisão em um futuro repositório privado. Nenhum repositório remoto foi criado ou publicado nesta etapa. Os links não foram revalidados durante esta preparação.

O pacote original não inclui licença. Nenhuma licença foi atribuída nesta preparação; a decisão sobre distribuição permanece pendente.
