# Campo Aberto — diretório OSINT

Painel estático em português com 20 fontes públicas de OSINT (inteligência de fontes abertas), com busca e filtros por categoria.

## Como usar

Baixe o repositório (**Code → Download ZIP**) ou clone-o, e abra `index.html` no navegador. Não precisa de instalação, conta, servidor nem dependências. Os detalhes estão em [LEIA-ME.md](LEIA-ME.md).

## Escopo

O painel é só um diretório de links: não faz consultas automáticas, não coleta nem armazena dados. Os links externos precisam de internet e podem mudar; confirme as condições de uso de cada serviço. A lista comentada das fontes, conferidas em 21/10/2026, está em [fontes-verificadas.md](fontes-verificadas.md).
